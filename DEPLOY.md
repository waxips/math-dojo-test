# Как опубликовать Math Dojo на GitHub Pages

## Вариант A: GitHub Desktop (без терминала)

1. Создайте на GitHub репозиторий, например `math-dojo`.
2. Распакуйте архив с сайтом.
3. В GitHub Desktop добавьте локальную папку с `index.html` как репозиторий или создайте репозиторий из этой папки.
4. Выполните commit и Publish / Push в созданный репозиторий.
5. На GitHub откройте **Settings → Pages → Build and deployment**.
6. **Source: Deploy from a branch → Branch: main → Folder: /(root) → Save**.
7. Ссылка на опубликованный сайт появится в разделе Pages. Обычно это `https://ВАШ_НИК.github.io/math-dojo/`.

Важно: **на верхнем уровне репозитория должны быть `index.html`, `.nojekyll` и `trainers/`.** Если там единственная папка с проектом, Pages не увидит главную страницу.

## Вариант B: терминал

Внутри папки распакованного проекта:

```bash
git init
git add .
git commit -m "Publish Math Dojo"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/math-dojo.git
git push -u origin main
```

После этого зайдите в **Settings → Pages** и настройте публикацию из `main / (root)` как в варианте A. Если репозиторий уже существует и связан с другой историей, сперва проверьте состояние Git — не выполняйте эти команды вслепую поверх старого проекта.

## Как расширить библиотеку подготовленных вопросов

Исходник — `source/library/questions.json`. Можно добавлять собственные вопросы, новые типы и новые темы, не меняя интерфейс. Подробнее: `source/library/ADDING_QUESTIONS.md`. После изменения выполните `python source/library/build.py` и загрузите обновлённые файлы на GitHub Pages. Импорт JSON через браузер — только временный, он не меняет опубликованный репозиторий.

## Как добавить раздел

- Положите новый `*.html` в папку `trainers/`.
- Добавьте карточку со ссылкой `trainers/имя.html` в `index.html`.
- Если новый тренажёр использует картинки или стили отдельными файлами, используйте относительные пути, например `../assets/...`, а не `/assets/...` — сайт может размещаться внутри `/math-dojo/`.
- Сделайте commit и push; опубликованная версия обновится.

## Проверка до публикации

Можно просто открыть `index.html` в браузере и перейти по темам. Если нужно протестировать сайт через локальный веб-сервер, из папки проекта выполните:

```bash
python -m http.server 8000
```

После чего откройте `http://localhost:8000/`.

## Важные детали

- Серверных функций здесь нет, GitHub Pages подходит для сайта в текущем виде.
- Все страницы существуют как статические файлы. Внешний хостинг шрифтов, аналитика и реклама не подключены.
- GitHub Pages **не** является закрытым пространством для личных данных учеников. Публикуйте только общие учебные материалы.
- Для других названий репозитория меняется только адрес; абсолютные пути в файлах не используются.
