# Библиотека осмысленных шагов: как добавлять задания

Страница `trainers/strategy_library.html` — готовая **автономная сборка**. Её не требуется изменять вручную. Исходник банка — `source/library/questions.json`. Сборка: `python source/library/build.py` из корня репозитория.

## Структура

В JSON есть три словаря подписей и список вопросов:

- `topics` — ID темы → название, например `calculations` → «Вычисления»;
- `skills` — ID типа → название («Понять цель», «Выбрать начало», «Найти ошибку» и т. п.);
- `difficulties` — число сложности → видимая подпись;
- `questions` — записи с уникальными `id`, `topic`, `skill`, `difficulty`, `expression`, `question`, `options`, `correct`, `hint`, `explanation`.

Минимальная запись (для нового вопроса об уравнениях):

```json
{
  "id": "L11",
  "topic": "linear",
  "skill": "start",
  "difficulty": 1,
  "expression": "x − 5 = 9",
  "question": "Какое действие сразу оставит x отдельно?",
  "options": [
    {"id": "a", "text": "Прибавить 5 к обеим частям", "feedback": "Это компенсирует вычитание пяти слева."},
    {"id": "b", "text": "Вычесть 5 из обеих частей", "feedback": "Так вычитание не исчезает."},
    {"id": "c", "text": "Разделить обе части на 5", "feedback": "Пятёрка вычитается, а не умножает x."}
  ],
  "correct": "a",
  "hint": "Какое действие обратно вычитанию пяти?",
  "explanation": "x − 5 = 9 → x = 14."
}
```

**Важно:** правильный вариант задаётся ID (`correct`), а не номером кнопки. Кнопки при прохождении перемешиваются. Каждое задание поддерживает 2–4 варианта (не обязательно 4, если трудно подобрать осмысленные ошибки).

### Как пополнять с помощью ChatGPT

Можно присылать таблицу вида:

| ID | Тема | Тип | Сложность | Выражение | Вопрос | А | Б | В | Г | Правильный вариант | Подсказка | Объяснение |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| L11 | Линейные уравнения | Выбрать начало | 1 | x − 5 = 9 | Как изолировать x? | Прибавить 5 к обеим частям | Вычесть 5 из обеих | Разделить обе части на 5 | — | А | Как отменить −5? | x = 14 |

Эта таблица предназначена для редакторской работы. При переносе в JSON **добавьте объяснения к каждому неправильному варианту**; механический перенос таблицы без проверки математического смысла недостаточен.

## Математические формулы (LaTeX)

В дополнение к обычным текстовым полям вопрос может содержать LaTeX. Это **не** язык, который обязан вводить ученик: запись только для красивого отображения условия, вариантов и объяснений.

- `expressionLatex` — формула условия; `expression` остаётся текстовым вариантом на случай недоступного KaTeX.
- `questionLatex` — вопрос вместо `question`.
- `options[].latex` — математическая запись отдельного варианта вместо `options[].text`.
- `hintLatex`, `explanationLatex` — подсказка и итоговый разбор.
- Внутри текстовых полей также поддерживаются `\\(x^2+1\\)` и `\\[\\frac{1}{2}\\]`. В JSON обратный слеш записывается как `\\`.

Например, для записи `\frac{1}{2}` в JSON потребуется строка `"expressionLatex": "\\frac{1}{2}"`. Не удаляйте обычные текстовые поля: они позволяют читать вопрос без интернета или при ошибке формулы.

Пример с отдельными вариантами:

```json
{
  "expression": "(x + 2)²",
  "expressionLatex": "(x+2)^2",
  "options": [
    {"id": "a", "text": "x² + 4x + 4", "latex": "x^2+4x+4", "feedback": "Квадрат суммы включает два смешанных произведения."},
    {"id": "b", "text": "x² + 4", "latex": "x^2+4", "feedback": "Здесь пропущен смешанный член."}
  ]
}
```

В этом примере показан только фрагмент задания, а не полная запись. Рендер использует KaTeX, загружаемый из CDN; при недоступности библиотеки показывается текст. Сетевой API для решения задач не используется.

## Подключение новой темы

1. Допишите новую запись в `topics`, например `"geometry": "Геометрия"`.
2. Используйте `topic: "geometry"` в новых заданиях. Тип можно брать из существующего `skills` или добавить свой.
3. Каждая запись должна иметь уникальный ID. Новая тема автоматически появится в фильтре, и новая сложность — в фильтре сложности.
4. Выполните `python source/library/build.py`, затем `node tests/verify_library.js` и по возможности `python tests/browser_library.py`.
5. Опубликуйте обновлённый `trainers/strategy_library.html` **вместе** с изменённым `source/library/questions.json`.

Внутри сайта можно выбрать «Дополнить или сохранить библиотеку» → «Импортировать JSON», чтобы просмотреть и попробовать свой банк сразу. **Импорт заменяет текущий банк в этой вкладке** (не добавляет записи к исходному файлу сайта). Для изменения опубликованного сайта обязательно обновите исходный JSON и пересоберите страницу.

## Правила качества педагогических вопросов

1. Сперва определите **какое затруднение** проверяет вопрос (чтение условия / структура / следующий шаг / проверка / завершение), затем пишите варианты.
2. Не формулируйте «единственно правильный первый шаг», если возможны альтернативные корректные стратегии. Уточните цель или используйте вопрос о верности предложенного преобразования.
3. Неверные варианты должны быть ошибочными **в контексте точного условия**, а не просто непривычными или менее красивыми.
4. Проверяйте арифметику, скобки, знаки, порядок действий и корректность всех отвлекающих вариантов вручную. Автоматические тесты проверяют структуру, а не педагогический смысл каждой формулировки.
5. Избегайте подсказок, которые по слову сразу выдают ответ. После подсказки всё ещё нужно думать.
6. Желательно после работы с выбором попросить ученика решить аналогичную задачу самостоятельно без вариантов.
7. Избегайте «игровых» искусственных метрик и давления на скорость. Оценка только по количеству правильных ответов не диагностирует причину затруднения.
