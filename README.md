# Math Dojo — учебный портал по математике

Небольшой статический сайт с каталогом из **12 тематических тренажёров**. Задания рассчитаны на самостоятельную тренировку базовой математики: вычисления, дроби, алгебра, уравнения, графики и геометрия.

Главные принципы: **попытка → обратная связь → понимание**. Без таймеров, аккаунтов, рекламных блоков и таблиц лидеров. Некоторые тренажёры поддерживают подсказки и повторные попытки. Более новые разделы дают небольшое объяснение после ответа.

## Быстрая публикация на GitHub Pages

**В архиве `index.html` уже находится в корне. Ничего собирать не надо.**

1. Создайте новый репозиторий GitHub, например `math-dojo` (для обычного бесплатного GitHub Pages проще использовать публичный репозиторий).
2. Распакуйте ZIP и поместите **содержимое архива** в корень репозитория (не дополнительную папку `Math-Dojo-Pages`). Должно быть `index.html`, папка `trainers/` и файл `.nojekyll` на верхнем уровне.
3. Откройте репозиторий → **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)**, нажмите **Save**.
6. После публикации адрес сайта будет вида `https://ВАШ_НИК.github.io/math-dojo/` (если репозиторий называется `math-dojo`). Для репозитория `ВАШ_НИК.github.io` адрес будет `https://ВАШ_НИК.github.io/`.

Подробности и вариант загрузки через Git: [DEPLOY.md](DEPLOY.md).

> Важно: GitHub Pages публикует сайт в интернете. Не помещайте в репозиторий персональные данные учеников или другие конфиденциальные материалы.

## Разработка и расширение

- Для редактирования каталога: `index.html` — каждая карточка темы представляет собой обычную HTML-ссылку с `data-topic` и `data-search`.
- Для правок к девяти оригинальным тренажёрам: `source/legacy/app.js`, `source/legacy/style.css`; потом выполните `python source/legacy/build.py` из корня проекта. Скрипт пересоздаёт только **девять** первоначальных страниц в `trainers/` и сохраняет ссылки «Каталог».
- Для двух новых тем: `source/focused/engine.js`, `source/focused/style.css`; выполните `python source/focused/build.py`. Пересоздаются только `formulas.html` и `zero_product.html`.
- `trainers/arithmetic_plus.html` — самостоятельный HTML-файл; его можно редактировать напрямую.
- Для новой темы можно добавить `trainers/new_topic.html` и соответствующую карточку на главной.

Если на компьютере есть Node.js, генераторы новых упражнений можно дополнительно проверить командой `node tests/verify_generators.js` (для работы сайта Node.js не нужен).

**Небольшое ограничение:** исходные девять тренажёров — учебные прототипы, некоторые их вопросы проще новых. Перед назначением конкретной серии ученику полезно просмотреть сгенерированные задания и при необходимости расширять объяснения в исходном коде.

## Для учеников

Откройте каталог, выберите тему и решайте задачи. Ошибка — повод воспользоваться подсказкой и восстановить рассуждение, а не основание торопиться дальше. Результаты не отправляются преподавателю автоматически; если нужна обратная связь, можно обсудить трудные задания на занятии.
