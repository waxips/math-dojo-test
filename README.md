# Math Dojo — учебный портал по математике

Небольшой статический сайт с каталогом из **12 тематических тренажёров** и двух дополнительных режимов ориентировки — бесконечного генератора «Как начать?» и библиотеки 30 проверенных заданий. Задания рассчитаны на самостоятельную тренировку базовой математики: вычисления, дроби, алгебра, уравнения, графики и геометрия.

Главные принципы: **попытка → обратная связь → понимание**. Без таймеров, аккаунтов, рекламных блоков и таблиц лидеров. Некоторые тренажёры поддерживают подсказки и повторные попытки. Более новые разделы дают небольшое объяснение после ответа.

## Быстрая публикация на GitHub Pages

**В архиве `index.html` уже находится в корне. Ничего собирать не надо.**

1. Создайте новый репозиторий GitHub, например `math-dojo` (для обычного бесплатного GitHub Pages проще использовать публичный репозиторий).
2. Распакуйте ZIP и поместите **содержимое архива** в корень репозитория (не дополнительную папку `Math-Dojo-Pages`). Должно быть `index.html`, папка `trainers/` и файл `.nojekyll` на верхнем уровне.
3. Откройте репозиторий → **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)**, нажмите **Save**.
6. После публикации адрес сайта будет вида `https://ВАШ_НИК.github.io/math-dojo/` (если репозиторий называется `math-dojo`). Для репозитория `ВАШ_НИК.github.io` адрес будет `https://ВАШ_НИК.github.io/`.

Подробности и вариант загрузки через Git: [DEPLOY.md](DEPLOY.md).

> Важно: GitHub Pages публикует сайт в интернете. Не помещайте в репозиторий персональные данные учеников или другие конфиденциальные материалы.

## Экспериментальный режим «Как начать?»

**Ссылка:** `trainers/how_to_start.html`. Через `?topic=calculations`, `?topic=linear` или `?topic=identities` можно сразу открыть вычисления, линейные уравнения или формулы сокращённого умножения.

Методические принципы и известные ограничения описаны в [`PEDAGOGY.md`](PEDAGOGY.md).

Это **добровольное дополнение** к обычной тренировке: существующие двенадцать тематических тренажёров сохранены. В пилоте используются **только три перечисленные темы**. Даже если некоторые другие темы доступны в общем каталоге, в эксперименте их нет.

Каждая серия содержит 10 вопросов из пяти педагогически отобранных семейств (каждое семейство появляется дважды с новыми числами). Режим тренирует чтение математической записи, распознавание цели, выбор действия, продолжение и завершение решения. Варианты не сочиняются произвольно: они берутся из проверенных шаблонов ошибок. Объяснение к неправильному варианту не раскрывает правильный ответ сразу; можно повторить попытку или открыть разбор.

**Важно:** это тестовая дидактическая гипотеза, а не замена преподавателя. Она не распознаёт произвольную формулу или все допустимые математические стратегии, и не даёт достоверной психологической диагностики по 10 ответам.

Устройство: `source/orientation/engine.js` — генераторы и банк действий; `app.js` — интерфейс и обратная связь; `extra.css` — дополнительные стили поверх исходной палитры; `build.py` — сборка автономного `trainers/how_to_start.html`. Сборка: `python source/orientation/build.py`.

Проверка генераторов: `node tests/verify_orientation.js`. При установленном Playwright для Python и Chromium дополнительная проверка интерфейса запускается командой `python tests/browser_smoke.py`; она исполняет готовые HTML-страницы в браузере без сетевой навигации. Тест ссылки до GitHub Pages не проверяет — после публикации их следует открыть вручную.

## Три слоя тренировки

Все обычные разделы и прежний экспериментальный генератор сохранены. На главной странице есть секция **«Выбирай, как учиться»** с тремя самостоятельными направлениями:

1. **Обычная тренировка:** существующие задания на вычисления, ввод ответа и выбор вариантов (все 12 прежних тем).
2. **Бесконечный «Как начать?»:** случайные вопросы на ориентировку в задании по трём пилотным темам (`trainers/how_to_start.html`). Никаких изменений в его математических генераторах не требуется.
3. **Библиотека заданий:** вручную составленные **30 фиксированных вопросов (по 10 на каждую из трёх тем)** (`trainers/strategy_library.html`).

**Только три пилотные темы второго и третьего слоя:** вычисления, линейные уравнения, формулы сокращённого умножения. Дроби, проценты, степени, квадратные функции и т. д. доступны в обычном каталоге, но **не входят** в два экспериментальных режима.

### Возможности библиотеки

- Таблица с поиском, фильтрами **по теме, типу вопроса, сложности** и сортировкой по ID, теме, типу и сложности в обоих направлениях.
- Ручная отметка упражнений; составление серии по отмеченным или текущему фильтру, выбор числа заданий и порядка (перемешанный / по таблице).
- Подсказки, по-выборная обратная связь, повторная попытка, разбор, итоговая сводка без таймеров и рекламных элементов.
- Экспорт JSON, импорт собственной библиотеки JSON в открытую страницу (без сервера). **Импорт временный и заменяет банк в текущей вкладке.** Для постоянного изменения сайта необходимо изменить исходный JSON и пересобрать HTML.
- Непосредственное открытие локального `index.html` или размещение на GitHub Pages. Сборка страницы содержит встроенный JSON и не требует сетевых запросов.

Данные банка: [`source/library/questions.json`](source/library/questions.json). Читаемая Markdown-таблица: [`source/library/QUESTIONS_INDEX.md`](source/library/QUESTIONS_INDEX.md). Инструкция по структуре, созданию новых вопросов и добавлению тем: [`source/library/ADDING_QUESTIONS.md`](source/library/ADDING_QUESTIONS.md).

Пересборка после изменений: `python source/library/build.py`. Тест структуры: `node tests/verify_library.js`. Дополнительный браузерный тест: `python tests/browser_library.py` (нужны Playwright и Chromium на компьютере разработчика).

**Педагогическое ограничение:** библиотека намеренно конечная, и варианты в ней вручную спроектированы, но не проверены полноценным педагогическим исследованием. Генератор может быть более разнообразным по числам, а библиотека — более осмысленной по ситуациям; какая стратегия помогает ученику, нужно проверять на реальной практике.

## Разработка и расширение

- Для редактирования каталога: `index.html` — каждая карточка темы представляет собой обычную HTML-ссылку с `data-topic` и `data-search`.
- Для правок к девяти оригинальным тренажёрам: `source/legacy/app.js`, `source/legacy/style.css`; потом выполните `python source/legacy/build.py` из корня проекта. Скрипт пересоздаёт только **девять** первоначальных страниц в `trainers/` и сохраняет ссылки «Каталог».
- Для двух новых тем: `source/focused/engine.js`, `source/focused/style.css`; выполните `python source/focused/build.py`. Пересоздаются только `formulas.html` и `zero_product.html`.
- `trainers/arithmetic_plus.html` — самостоятельный HTML-файл; его можно редактировать напрямую.
- Для новой темы можно добавить `trainers/new_topic.html` и соответствующую карточку на главной.

Если на компьютере есть Node.js, генераторы новых упражнений можно дополнительно проверить командой `node tests/verify_generators.js` (для работы сайта Node.js не нужен).

**Небольшое ограничение:** исходные девять тренажёров — учебные прототипы, некоторые их вопросы проще новых. Перед назначением конкретной серии ученику полезно просмотреть сгенерированные задания и при необходимости расширять объяснения в исходном коде.

## Для учеников

Откройте каталог, выберите тему и решайте задачи. Ошибка — повод воспользоваться подсказкой и восстановить рассуждение, а не основание торопиться дальше. Результаты не отправляются преподавателю автоматически; если нужна обратная связь, можно обсудить трудные задания на занятии.
